# 설계 결정 기록

이 프로젝트는 "MVP는 에이전트가 구현, 이후 개량은 사용자가 직접"으로 진행한다. 누가 무엇을 정했는지 추적하는 것이 목적이다.

결정자 값은 세 가지뿐이다.

- **사용자**: 사용자가 채팅에서 직접 정한 것.
- **AI-지시문**: 에이전트에게 준 지시문의 [기술 결정], [운영 한도], 각 작업에 적힌 설계.
- **AI-구현**: 지시문에 없지만 구현하려면 꼭 필요했던 선택(라이브러리 버전, 패키지 구조, 클래스 분리, 테스트 도구 등).
